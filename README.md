# Æther Inc. - コーポレートランディングページ

架空のIT企業「Æther Inc.」を想定した、モダンでスタイリッシュなテック系コーポレートサイトのランディングページです。

##  技術スタック
- **HTML5** （BEM記法によるクリーンなクラス設計）
- **CSS3** （CSS変数、`clamp()` による流動的タイポグラフィ、ダークテーマ）
- **JavaScript (Vanilla)** （完全シームレスなロゴの無限ループ、レスポンシブなハンバーガーメニュー制御）

##  特徴
- **デザイン性**: 近未来的なダークトーンと洗練されたグラデーション装飾。
- **パフォーマンス**: 余計なフレームワークや外部ライブラリに依存せず、プレーンなコードで超軽量かつ高速に動作。
- **レスポンシブ対応**: モバイルからデスクトップまでシームレスに適応。
